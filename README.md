# House Price Prediction using Machine Learning

## Project Overview
This project uses Machine Learning to predict house prices using the California Housing dataset. It explores housing data, performs exploratory data analysis (EDA), preprocesses the data, and builds a Linear Regression model to predict house values.

## Objectives
- Explore and analyze the California Housing dataset.
- Perform exploratory data analysis and visualization.
- Preprocess and normalize the dataset.
- Train a Linear Regression model.
- Evaluate model performance using regression metrics.
- Save the trained model using Pickle.

## Technologies Used
- Python
- Pandas
- NumPy
- Matplotlib
- Seaborn
- Scikit-learn
- Jupyter Notebook

## Workflow
1. Load the California Housing dataset.
2. Perform data exploration and statistical analysis.
3. Visualize feature distributions and correlations.
4. Split data into training and testing sets.
5. Normalize the features.
6. Train a Linear Regression model.
7. Evaluate predictions using MSE, MAE, RMSE, and R².
8. Save and load the trained model using Pickle.

## Model Performance
- Mean Squared Error (MSE): 0.5306
- Mean Absolute Error (MAE): 0.5272
- Root Mean Squared Error (RMSE): 0.7284
- R² Score: 0.5958

## How to Run
1. Clone this repository.
2. Install the required libraries:
   `pip install numpy pandas matplotlib seaborn scikit-learn jupyter`
3. Open the notebook:
   `jupyter notebook Predicting_House_Prices.ipynb
